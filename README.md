# Downr Vercel API

## Deploy
Upload this project to Vercel.

## Endpoint
GET /api/downr?url=VIDEO_URL

Example:
https://YOUR-PROJECT.vercel.app/api/downr?url=https%3A%2F%2Fexample.com%2Fvideo
